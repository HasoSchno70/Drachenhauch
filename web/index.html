GameBasic — Web-Playground

native Runtime gbrt als WebAssembly (experimentell)
lade … 

    

  


  

    Die Knöpfe oben laden je ein fertiges Beispiel und starten es sofort.
    ▶ Demo lädt das Programm, mit dem dieser Build gemacht wurde (samt
    seinen Assets); die übrigen Beispiele laden bewusst keine Dateien und
    laufen deshalb in jedem Build.
    Ton: Browser lassen Klang erst zu, nachdem man die Seite einmal
    angeklickt hat — bei einem Programm mit Musik also einmal ins Bild klicken.
    Tippe GameBasic-Quelltext links und klicke Ausführen — gbrt.wasm
    kompiliert die Quelle im Browser (kein Server, kein Pyodide) und führt
    sie aus: Konsolen-Ausgabe unter dem Canvas, Grafik im Canvas. Jeder Lauf
    startet eine frische Runtime. Link teilen packt die Quelle in die URL —
    wer den Link öffnet, sieht (und startet) genau dein Programm. Build via
    rust/build_wasm.py, Status & Grenzen:
    docs/web-playground.md.
