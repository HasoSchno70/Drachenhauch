# Englische Fassung der Meldungen von dhrt (DHRT_LANG=en).
#
# Je Zeile: deutsche Vorlage, TABULATOR, englische Fassung. Zeilen ohne
# Tabulator oder mit # vorn sind Kommentare.
#
# {} steht fuer ein eingesetztes Stueck. Im Englischen der Reihe nach, oder
# gezielt mit {1}, {2} ... (ab 1), wenn die Reihenfolge wechselt. {{ und }}
# sind geschweifte Klammern. Was ein Platzhalter einfaengt, wird seinerseits
# uebersetzt -- darum genuegen fuer zusammengesetzte Meldungen die Teile.
#
# Die genaueste Vorlage gewinnt (die mit den meisten festen Zeichen). Was
# keine trifft, bleibt deutsch. `dhrt pruef meldungen` prueft, dass jede
# deutsche Vorlage noch im Quelltext steht.
