# Gallery

Programs built with Drachenhauch -- to try out, read and learn from. Each
one is a public repository of its own or ships with this one.

## Games and demos

| Program | What it is |
|---|---|
| [Circuit Runner](../../spiele/circuitrunner/) | a puzzle platformer with a level editor and recordings of solved levels; ships with this repository |
| [Nachtflug](https://github.com/HasoSchno70/Nachtflug) | a trance demo: music, sounds and pictures from one program, [in the browser](https://hasoschno70.github.io/Nachtflug/) |
| [Lichterglanz](https://github.com/HasoSchno70/Lichterglanz) | a Christmas demo, music and pictures from one program, [in the browser](https://hasoschno70.github.io/Lichterglanz/) |

## Applications

| Program | What it is |
|---|---|
| [Glutfaden](https://github.com/HasoSchno70/Glutfaden) | a cross-stitch editor with GTK 3: patterns, thread palettes, layers, image import, PDF and OXS export |
| [Funkenflug](https://github.com/HasoSchno70/Funkenflug) | a schematic editor with GTK 3: perfboard and stripboard, KiCad import, Gerber, simulation with ngspice |
| [Kühlschrank](https://github.com/HasoSchno70/Kuehlschrank-Drachenhauch) | a Studio project for the fridge: stock, storage places, shopping, recipes, statistics, barcode scanning |
| The [IDE](ide.md) and the [Studio](studio.md) | the development environments themselves -- written in Drachenhauch, they ship with this repository |

## Libraries

The ones to fetch with `dhrt paket` are listed in the [package manual](pakete.md#packages-to-start-with).

## Show your own program

Built something? Show it under
[Show and tell](https://github.com/HasoSchno70/Drachenhauch/discussions/categories/show-and-tell)
in the discussions -- with a picture and a link. A program others can try
(a public repository, ideally with a version for the browser) goes into this
list on request: open a pull request with one line here and in
`docs/galerie.md`, or ask for it in your post. Questions belong under
[Q&A](https://github.com/HasoSchno70/Drachenhauch/discussions/categories/q-a).
