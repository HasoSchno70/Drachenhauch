==============================================================
Drachenhauch in PyCharm einrichten
==============================================================

1) PROJEKT-INTERPRETER AUF DIE .venv UMSTELLEN
----------------------------------------------
File -> Settings -> Project: Drachenhauch -> Python Interpreter
Zahnrad oben rechts -> "Add Interpreter" -> "Add Local Interpreter"
-> "Existing" -> Pfad waehlen:
    C:\Programmieren\Python\Drachenhauch\.venv\Scripts\python.exe
Bestaetigen. PyCharm sieht jetzt PySide6 und alle anderen Pakete.


2) RUN-KONFIGURATION FUER dhrun.py
----------------------------------
Rechtsklick auf dhrun.py -> "Modify Run Configuration..."
oder oben rechts -> "Edit Configurations..." -> "+ Python".

Name:               Pong (oder beliebig)
Script path:        C:\Programmieren\Python\Drachenhauch\dhrun.py
Parameters:         examples/10_pong.dh
Working directory:  C:\Programmieren\Python\Drachenhauch
Python Interpreter: Project Default (.venv)

Das gleiche kannst du fuer 09_shapes, 12_sprite, 13_sound usw.
duplizieren.


3) WENN PYCHARM NUR DIE EINZELDATEI ZEIGT
-----------------------------------------
Falls du bisher nur dhrun.py geoeffnet hast (kein Projektbaum):
  File -> Close Project
  File -> Open... -> ORDNER C:\Programmieren\Python\Drachenhauch auswaehlen
  -> "Trust Project"

Links das Projekt-Tool-Fenster mit Alt+1 einblenden.
Du siehst dann die Struktur:
  Drachenhauch/
    .venv/                  <- PyCharm verbirgt das oft, ist normal
    examples/
      assets/
      *.dh
    drachenhauch/              <- das ist das Python-Paket
      *.py
    dhrun.py
    pyproject.toml

5) STARTEN OHNE PYCHARM
-----------------------
Aus jedem Terminal im Projekt-Ordner:

    dh.cmd examples\10_pong.dh           (Windows-CMD/PowerShell)
    ./dh.sh examples/10_pong.dh          (Git-Bash, WSL)

beide nutzen automatisch den .venv-Python und brauchen nichts global.
Ohne Python geht es genauso:  dhrt run examples\10_pong.dh


6) SPIELE ALS .EXE VERTEILEN
----------------------------
Das macht die Laufzeit selbst -- PyInstaller und der fruehere `dh-package`
werden dafuer nicht mehr gebraucht:

    dhrt --export examples\10_pong.dh
        -> 10_pong_dist\10_pong.exe samt kopierter assets/

`dhrt --export` haengt den uebersetzten Bytecode an eine Kopie der Laufzeit.
Die Exe laeuft ohne Python und ohne Installation; weitergeben heisst: den
ganzen `_dist`-Ordner kopieren.

Sicherheitshinweis: Manche Antivirus-Programme melden frisch gebaute .exe
als verdaechtig (False Positive). Wenn das stoert, mit Microsoft Defender
ausschliessen oder die .exe signieren (erst exportieren, dann signieren --
umgekehrt zerstoert das Anhaengen die Signatur).
