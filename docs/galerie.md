# Galerie

Programme, die mit Drachenhauch gebaut sind -- zum Ausprobieren, Nachlesen
und Abschauen. Jedes ist ein eigenes, öffentliches Repository oder liegt
diesem bei.

## Spiele und Demos

| Programm | Was es ist |
|---|---|
| [Circuit Runner](../spiele/circuitrunner/) | ein Puzzle-Platformer mit Leveleditor und Aufnahmen gelöster Level; liegt diesem Repository bei |
| [Nachtflug](https://github.com/HasoSchno70/Nachtflug) | eine Trance-Demo: Musik, Klänge und Bilder aus einem Programm, [im Browser](https://hasoschno70.github.io/Nachtflug/) |
| [Lichterglanz](https://github.com/HasoSchno70/Lichterglanz) | eine Weihnachtsdemo, Musik und Bild aus einem Programm, [im Browser](https://hasoschno70.github.io/Lichterglanz/) |

## Anwendungen

| Programm | Was es ist |
|---|---|
| [Glutfaden](https://github.com/HasoSchno70/Glutfaden) | ein Kreuzstich-Editor mit GTK 3: Muster, Garnpaletten, Ebenen, Bildimport, PDF- und OXS-Export |
| [Funkenflug](https://github.com/HasoSchno70/Funkenflug) | ein Schaltplan-Editor mit GTK 3: Lochraster und Streifenraster, KiCad-Import, Gerber, Simulation mit ngspice |
| [Kühlschrank](https://github.com/HasoSchno70/Kuehlschrank-Drachenhauch) | ein Studio-Projekt: Vorrat, Lagerorte, Einkauf, Rezepte, Statistik, Barcode-Scan |
| Die [IDE](ide.md) und das [Studio](studio.md) | die Entwicklungsumgebungen selbst -- in Drachenhauch geschrieben, liegen diesem Repository bei |

## Ein eigenes Programm zeigen

Etwas gebaut? Zeig es unter
[Show and tell](https://github.com/HasoSchno70/Drachenhauch/discussions/categories/show-and-tell)
in den Discussions -- mit einem Bild und einem Link. Ein Programm, das
andere ausprobieren können (ein öffentliches Repository, am besten mit
einer Fassung für den Browser), kommt auf Wunsch in diese Liste: einen Pull
Request mit einer Zeile hier und in `docs/en/galerie.md` öffnen, oder im
Beitrag darum bitten. Fragen gehören unter
[Q&A](https://github.com/HasoSchno70/Drachenhauch/discussions/categories/q-a).
