# Code of Conduct / Verhaltenskodex

Drachenhauch is made for people who want to learn programming and for people
who build things with it. Everyone taking part in issues, pull requests and
discussions should be able to do so without being put down.

**We expect:** friendly and patient answers, especially to beginners;
criticism of code, not of people; accepting that others decide differently.

**Not acceptable:** insults, harassment, discrimination of any kind,
publishing other people's private data, sexualised language or images, and
deliberately derailing discussions.

**What happens:** the maintainer (GitHub user HasoSchno70) may edit or delete
contributions that break these rules and may block people who keep doing so.
To report something, use the private report function on GitHub (the "…" menu
of a comment, *Report content*) or open a
[private security report](https://github.com/HasoSchno70/Drachenhauch/security)
if it must stay confidential.

These rules are based on the ideas of the
[Contributor Covenant](https://www.contributor-covenant.org/).

---

Drachenhauch ist für Menschen gemacht, die Programmieren lernen wollen, und für
Menschen, die damit etwas bauen. Jeder, der bei Issues, Pull Requests und
Diskussionen mitmacht, soll das tun können, ohne herabgesetzt zu werden.

**Erwartet wird:** freundliche und geduldige Antworten, gerade an Einsteiger;
Kritik an Code, nicht an Menschen; hinnehmen, dass andere anders entscheiden.

**Nicht hingenommen werden:** Beleidigungen, Belästigung, Diskriminierung
jeder Art, das Veröffentlichen privater Daten anderer, sexualisierte Sprache
oder Bilder und absichtliches Entgleisenlassen von Diskussionen.

**Was dann passiert:** der Betreuer des Projekts (GitHub-Nutzer HasoSchno70)
darf Beiträge, die gegen diese Regeln verstoßen, bearbeiten oder löschen und
Menschen sperren, die es wiederholt tun. Melden lässt sich etwas über die
Meldefunktion von GitHub (Menü „…“ eines Kommentars, *Report content*) oder,
wenn es vertraulich bleiben muss, über eine
[private Meldung](https://github.com/HasoSchno70/Drachenhauch/security).
