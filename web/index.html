    Tippe GameBasic-Quelltext links und klicke Ausführen — gbrt.wasm
    kompiliert die Quelle im Browser (kein Server, kein Pyodide) und führt
    sie aus: Konsolen-Ausgabe unter dem Canvas, Grafik im Canvas. Jeder Lauf
    startet eine frische Runtime. Link teilen packt die Quelle in die URL —
    wer den Link öffnet, sieht (und startet) genau dein Programm. Build via
    rust/build_wasm.py, Status & Grenzen:
    docs/web-playground.md.
